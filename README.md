# مكتبة الأذان (adhani-sounds)

هذا المجلد يُرفع كما هو إلى مستودع GitHub عام، مع تفعيل GitHub Pages، فيقرأه تطبيق أذاني من:
`https://<اسم المستخدم>.github.io/adhani-sounds/catalog.json`

- `catalog.json`: قائمة الأصوات التي يعرضها التطبيق.
- `part1` … `part5/<id>.m4a`: الأذان كاملاً (أندرويد، والاستماع داخل التطبيق).
- `part1` … `part5/<id>-30.caf`: أول 30 ثانية للآيفون.

لإضافة أصوات: ضع التسجيلات في مجلد بأسماء مثل `Taha_Al_Junayd_طه_الجنيد.mp3`، ثم:
`node scripts/build-sound-library.mjs <مجلد التسجيلات> <هذا المجلد>`
(يحتاج ffmpeg). ارفع الناتج، ويظهر في التطبيق فوراً دون تحديث من المتجر.
